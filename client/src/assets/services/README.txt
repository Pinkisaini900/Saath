Drop real photos here and they appear automatically on the service cards.
Name each file after the service slug, for example:

  ac-repair.jpg   car-wash.jpg   home-cleaning.jpg
  water-purifier.jpg   pest-control.jpg   sofa-cleaning.jpg

Recommended size: 1280 x 800 (16:10), under 200 KB each. jpg, png, webp and avif work.
Services without a photo show a clean icon tile, so nothing ever looks broken.
For the home page hero, add src/assets/hero.jpg (about 1400 x 1000).
